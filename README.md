## 왜 만들었나

시중 공부 기록 앱은 대체로 "과목"이 자유 입력입니다. 그런데 변호사시험은 과목과 시험유형이 제도로 정해져 있어서, 매번 직접 쳐 넣으면 오타 하나에 통계가 갈라집니다. 헌법·행정법을 공법으로 묶어 보고 싶은데 그것도 안 됩니다.

그래서 **시험 체계를 코드에 박아둔** 기록 앱을 만들었습니다. 과목을 고르면 그 과목에 실제로 존재하는 시험유형만 뜹니다.

## 특징

**시험 체계에 맞춰져 있습니다**
상위분류(공법·민사법·형사법·상법·환경법) → 세부 과목 2단계로 고릅니다. 기록형이 없는 상법을 고르면 기록형 칩이 아예 안 뜨고, 환경법은 사례형만 뜹니다.

**시간이 중심입니다**
달력 칸 색이 그날 순공부시간을 하루 목표 대비 5단계로 보여주고, 목표를 채운 날엔 ✓가 붙습니다. 계획을 몇 개 끝냈는지는 칸 안에 작은 숫자로만 나옵니다.

**입력을 줄이려고 했습니다**
스톱워치를 멈추면 시간 칸이 자동으로 찹니다. 진도표를 등록해두면 날짜가 될 때 그날 몫이 계획에 들어옵니다. 채점 결과를 기다리는 시험은 따로 모아뒀다가 결과가 나오면 그 자리에서 점수만 넣습니다.

**선택형과 사례·기록형을 같은 형식으로 다룹니다**
선택형은 `맞은 / 푼`, 사례·기록형은 `득점 / 만점` — 둘 다 분자·분모 두 칸이고 옆에 정답률이 바로 뜹니다. 만점이 회차마다 달라도 추이 그래프는 득점률로 비교하니 왜곡되지 않습니다.

**서버가 없습니다**
기록은 브라우저에만 저장됩니다. 만든 사람을 포함해 누구에게도 데이터가 가지 않습니다. 인터넷이 끊겨도 그냥 쓰입니다.

**폰과 컴퓨터를 같이 씁니다**
본인 GitHub 계정의 gist에 저장해서 두 기기가 같은 내용을 봅니다. 양쪽에서 따로 입력해도 항목 단위로 합쳐지고, 한쪽에서 지운 기록이 동기화하면서 되살아나지 않습니다.

**아이폰에서 제대로 보입니다**
다이내믹 아일랜드·홈 인디케이터를 피하고, 좁은 화면에서는 표가 카드 형태로 펼쳐집니다. 홈 화면에 추가하면 앱처럼 열립니다.

## 과목 체계

| 상위분류 | 세부 과목 | 시험유형 |
|---|---|---|
| 공법 | 헌법 / 행정법 | 기록형 · 사례형 · 선택형 |
| 민사법 | 민법 / 민사소송법 | 기록형 · 사례형 · 선택형 |
| 형사법 | 형법총론 / 형법각론 / 형사소송법 | 기록형 · 사례형 · 선택형 |
| 상법 | — | 사례형 · 선택형 |
| 환경법 | — | 사례형 |

기록형은 상위분류로만 기록합니다(세부 과목이 뜨지 않습니다). 세부 과목은 복수 선택할 수 있고, 그럴 때 통계에서는 시간을 나눠 계산합니다.

기록형·사례형·선택형 셋은 코드에 고정이고, 그 밖의 유형(최신판례, 진도별 모의고사 등)은 설정에서 직접 추가·삭제합니다.

## 써보기

**1. 그냥 열어보기**

[데모 주소](https://jay77-star.github.io/LawschoolStudyPlanner/)를 열면 바로 씁니다. 기록은 그 브라우저에만 남습니다. 지금 화면이 마음에 드는지 보는 용도로 충분합니다.

**2. 내 것으로 만들기**

이 저장소를 Fork → Settings → Pages → Source를 `main` 브랜치로 → 몇 분 뒤 `https://<내아이디>.github.io/<저장소이름>/` 이 열립니다. 파일 이름은 `index.html`이어야 합니다.

**3. 폰과 동기화하기** (선택)

GitHub에서 토큰을 하나 만들어 넣으면 됩니다.

- Settings → Developer settings → **Personal access tokens (classic)** → Generate new token
- 권한은 **`gist` 하나만** 체크
- 만들어진 `ghp_...` 문자열을 앱의 `설정 → 기기 간 동기화`에 붙여넣고 연결
- 폰에서도 같은 주소에 접속해 같은 토큰을 한 번 넣으면 이어집니다

저장 공간은 자동으로 만들어집니다. 토큰 화면을 벗어나면 값을 다시 볼 수 없으니 폰에 넣을 때까지 잠깐 어딘가에 두었다가, 끝나면 지우세요.

## 데이터와 프라이버시

**기록은 브라우저의 `localStorage`에 저장됩니다.** 서버로 보내지 않습니다. 이 저장소를 만든 사람도 여러분의 기록을 볼 수 없습니다.

**동기화를 켜면** 여러분 본인의 GitHub 계정에 gist가 하나 만들어지고 거기에 저장됩니다. 제3자 서버를 거치지 않습니다.

**다만 알고 계셔야 할 것이 있습니다.** 이때 쓰는 gist는 `public:false`로 만들어지는데, GitHub에서 이건 "비공개"가 아니라 **"목록에 안 뜸"** 입니다. 검색이나 Discover에는 안 나오지만 **URL을 아는 사람은 로그인 없이 볼 수 있습니다.** gist 주소는 32자리 16진수라 우연히 맞힐 일은 사실상 없지만, 그 주소를 아무 데나 붙여넣지 마세요. 민감한 내용을 메모에 적으실 거라면 이 점을 감안하시고요.

**토큰 권한을 `gist`로만 두는 이유가 있습니다.** 그 토큰으로는 저장소 코드도, 계정 설정도 건드릴 수 없습니다. 다른 권한을 같이 체크하지 마세요. 토큰은 각 기기의 브라우저에만 저장되고 동기화 대상이 아닙니다. 백업 파일에도 들어가지 않습니다.

**브라우저 저장소는 영구적이지 않습니다.** 사이트 데이터를 지우거나 시크릿 창을 닫으면 기록이 날아갑니다. `설정 → 백업 파일 저장(.json)`을 가끔 눌러두세요.

## 안 되는 것

솔직하게 적어둡니다.

- **알림이 없습니다.** 웹앱이라 "기록할 시간입니다" 같은 푸시를 보낼 수 없습니다.
- **잠금화면 스톱워치가 안 됩니다.** iOS의 Live Activities는 네이티브 앱 전용이라 웹에서는 통로가 없습니다. 대신 화면을 꺼도 시간은 정확히 흘러갑니다.
- **여러 사람이 같이 쓸 수 없습니다.** 1인용입니다.
- **아이폰 14 Pro Max와 데스크톱에서만 실제로 확인했습니다.** 다른 기기에서 어긋나는 부분이 있을 수 있습니다.

## 기술

의존성이 없습니다. HTML·CSS·JavaScript 한 파일(약 2,500줄)이고 빌드 단계도 없습니다. 파일을 열면 그게 앱입니다.

동기화는 GitHub Gist API를 직접 호출합니다. 두 기기의 데이터를 합칠 때는 항목 id를 기준으로 합치고 마지막 수정 시각이 늦은 쪽을 남깁니다. 삭제는 따로 기록해둬서 동기화하면서 되살아나지 않게 했습니다.
